Roundtable asks several AIs the same question. You see each answer side by side. Then one AI, the chair, writes one clear verdict.

Everything runs on this computer, with your own AI accounts. Roundtable itself is free.

## Start here

- [Getting started](getting-started.md): ask your first question and read the verdict.
- [Connect your AIs](connect-your-ais.md): use the AI apps you already have, or add an API key.
- [Personas and rounds](personas-and-rounds.md): give each seat a role, and let the AIs argue.
- [Deep Think and Quick](deep-think.md): a fast answer, or a long, careful one.
- [Decision model and Jebadiah](decision-model.md): a second opinion on the verdict.
- [Use Roundtable from your AI](use-from-your-ai.md): ask the roundtable from inside Claude.
- [Keyboard shortcuts](keyboard-shortcuts.md): every key the app knows.

## More help

- Help, What's new lists every change in each version.
- Help, Online docs opens these pages and more on roundtable.sh.
- Help, Report a problem opens a short form on GitHub. Your app version and system are filled in for you.
- Settings, Help, Copy diagnostics copies versions, your system and which AIs are set up. It never copies a key.
