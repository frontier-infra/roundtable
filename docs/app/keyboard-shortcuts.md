On Windows, use Ctrl where a Mac uses Cmd.

## Anywhere

- Cmd+Comma opens Settings.
- Cmd+Shift+/ opens this help on a Mac. F1 opens it on Windows.
- Cmd+Q quits Roundtable. On Windows, use File, Exit or Alt+F4.
- Control+Cmd+F enters full screen on a Mac. F11 does it on Windows.
- Escape closes What's new, About and other sheets.

## Asking

- Cmd+Enter asks the table from the question box.
- Cmd+Enter sends a follow-up from the follow-up box.
- Enter adds a link from the link box.
- Enter checks and saves a key you pasted.

## Past roundtables

- Up and Down arrows move through the list.
- Enter opens the roundtable you are on.
- Delete or Backspace deletes it. Cmd+Z brings it back while Undo shows.
- Cmd+click picks several. Shift+click picks a range.
- Space picks a row in Select mode. Escape leaves Select mode.
- Right-click, or the menu key, shows Open and Delete.

## Text

Cut, copy, paste, undo and select all work as usual in every box.
